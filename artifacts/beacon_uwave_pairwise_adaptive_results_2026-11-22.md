## Данные и методы

Именно классическая UEA UWaveGestureLibrary из aeon 1.5.0: 120 TRAIN, 320 TEST, три канала акселерометра, 315 отсчётов и восемь классов. Это не UCR UWaveGestureLibraryAll и не более поздняя пересборка. TRAIN разбит внутри каждого класса на 12 окон для обучения фиксированной ExtraTrees (96 всего) и три на калибровку Ridge (24 всего), seed 57. Нормировка, class profiles, доноры, обучение и калибровка исключительно по TRAIN; надёжного разделения по участникам/сеансам в архиве нет.

ExtraTrees с 120 деревьями показала **TEST accuracy = 199/320 = 62,1875%**, ниже заранее заданного порога 70%. Результат нельзя выдавать за доказательство качественного объяснения точной модели.

Для каждого TEST окна A — исходный argmax, B — исходный runner-up замороженного классификатора; метки TEST в поиске не участвуют. Два разных ближайших по L2 TRAIN-донора, предсказанных моделью как B; ни одному окну не недоставало двух доноров. Оператор — десять неперекрывающихся временных блоков по трём каналам, taper 2, не более 35% изменённых координат у каждого донора. Общий Q8 или Q16 относится к числу **реально оценённых моделью входов на обоих донорах вместе**.

Ridge обучен на 1152 TRAIN-only фактических оценках масок: 10 одиночных, 9 парных и 5 тройных масок для каждого из двух доноров на 24 отдельных калибровочных записях. Параметры alpha=10 и начальное ковариационное приближение posterior зафиксированы заранее. Два признаковых варианта: сумма статистических gain плюс 10 индикаторов компонентов; второй плюс 45 индикаторов присутствия пар. Парный Ridge чуть лучше подгоняет **TRAIN** (MAE 0,558 против 0,576), однако это не оценка обобщения и не причинная атрибуция.

## TEST: прямое подтверждение B для двух доноров с компактной маской

| Метод | Q8: подтверждений из 320 | Q16: подтверждений из 320 | Из них Q16 с изменением ≤20% | Проверена 1-deletion минимальность при Q16 | Среднее онлайн Q16 |
|---|---:|---:|---:|---:|---:|
| Исходный STATIC SPARSE BEACON | 108 | 141 | 99 | 125 | 13,22 |
| PAIRS STATIC (обученные пары, без обновлений) | 113 | 136 | 98 | 123 | 12,59 |
| PAIRS ADAPTIVE (пары и обновление) | 128 | **160** | 109 | 142 | 12,40 |
| **ADDITIVE ADAPTIVE** (без pair-признаков) | **142** | **175** | **136** | **160** | **11,85** |

**Единственная заранее определённая первичная пара Q16:** PAIRS ADAPTIVE против STATIC SPARSE: оба подтвердили 121 окно, только PAIRS ADAPTIVE — 39, только STATIC — 20, оба отказали — 140. Разница **+19/320 = +5,9375 п.п.**, двусторонний точный Мак-Немар **p=0,0183371**.

Однако PAIRS STATIC уступает исходному по Q16 (136 против 141), а ADDITIVE ADAPTIVE превосходит PAIRS ADAPTIVE (175 против 160) по наблюдаемому результату. Попарное p≈0,0489 для ADDITIVE против PAIRS — **разведочное** после нескольких сравнений, не подтверждающая первичная гипотеза. Новизна 45 парных коэффициентов как полезного улучшения **не подтверждена**.

## Проверка переноса на незадействованных донорах D3 и D4

После завершения каждого успешного Q16 поиска выбранная маска была отдельно применена к двум другим TRAIN-донорам. Эти **1224 дополнительных модельных оценки учитывались отдельно и никогда не влияли на Q16**, не являются онлайн-сертификатом.

| Метод | Успехов D1+D2 | Перенеслись на те же классы D3+D4 | Доля переноса среди успехов |
|---|---:|---:|---:|
| STATIC SPARSE | 141 | 73 | 51,8% |
| PAIRS STATIC | 136 | 63 | 46,3% |
| PAIRS ADAPTIVE | 160 | 68 | 42,5% |
| ADDITIVE ADAPTIVE | 175 | 68 | **38,9%** |

Наиболее высокий охват двух заранее выбранных доноров **сопровождается худшим переносом фиксированной маски** на следующие два. Оптимизация только по D1+D2 может усиливать донороспецифичность, а не выявлять устойчивую структуру объяснения.

## Интерпретация и дальнейшая работа

Исследовательский признак пользы локальной **адаптации к измеренным откликам** есть, но при невысокой accuracy модели. Обучение pairwise interactions на 24 калибровочных окнах не оправдало более высокую сложность относительно аддитивной адаптации. Суррогат не является математической гарантией успеха; гарантия только для фактически измеренных D1 и D2 при данном операторе, не для любых доноров, реальных движений или причинных эффектов.

**Следующий приоритет:** проверить ADDITIVE ADAPTIVE и PAIRS ADAPTIVE на другой архитектуре и новом корпусе с accuracy объясняемой модели ≥70%, сделать метрикой одновременно компактный охват и фактический перенос на новые донорные окна. Нельзя подбирать модель, Q, пороги и пары по уже просмотренному TEST UWave и затем утверждать независимую репликацию.
