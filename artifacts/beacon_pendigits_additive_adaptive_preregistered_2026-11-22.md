# Независимая проверка BEACON на PenDigits: ADDITIVE ADAPTIVE против STATIC, общие Q8/Q16

**Фиксация: 22 ноября 2026, до открытия TEST PenDigits.** Объясняемая модель для этого этапа — уже существующая raw_mlp из fit_predictor, а не ExtraTrees, использованная на UWave. Исследовательская гипотеза выбрана по предыдущим UWave-результатам и поэтому НЕ может считаться независимо сформулированной от всей истории BEACON, но корпус PenDigits здесь не использовался.

Данные: официальный UEA PenDigits, TRAIN 7494, TEST 3498, 2 пространственных координатных канала, длина 8, десять цифр. 44 писавших человека, но IDs в матрице не представлены, независимость людей между TRAIN и TEST не подтверждена. Обязательная проверка размеров. Произвольная склейка рукописных координат не является физическим или причинным контрфактом.

TRAIN-only разбиение seed 57: ровно 10 примеров от каждого из десяти классов в calibration, остальные 7394 в trainfit. Замороженная MLP (один скрытый слой 32, alpha 0.01, max_iter 30, early stopping, random_state 57, как в общем fit_predictor), нормировка и class profiles из trainfit. Никаких изменений модели после просмотра TEST. Минимум желательной TEST accuracy 70%; если ниже, отмечать непригодность для сильного заявления о качестве объяснений.

Дополнительная модельная стоимость: исходные TEST прогнозы на 3498 окнах оплачиваются и сохраняются отдельно от Q, но **объяснения строятся только для 320 заранее выбраных тестовых окон**: первые 320 индексов из детерминированной перестановки 3498, np.random.default_rng(5712), затем отсортировать для воспроизводимости. Ни метки TEST, ни предсказания не используются для выбора этих 320 индексов.

Донорный банк TRAIN-fit: 16 записей на класс, seed 67, проверка их предсказания моделью отдельно от Q. Для A=исходный argmax и B=runner-up выбрать D1/D2 — два разных TRAIN-донора, предсказанных B, с минимумом полной среднеквадратичной дистанции, tie-break по train original index. Если нет двух, J=0, окно остаётся в знаменателе 320.

Оператор: 8 временных точек по двум каналам, 8 отдельных компонентов по одной временной точке, taper=0, поддержка не больше 35% изменённых координат для **каждого** из D1,D2. Это допускает не больше двух из восьми временных точек, за исключением совпадающих числовых значений. Общий Q8/Q16 на оба донора.

Обучить на калибровочных 100 TRAIN окнах два surrogate Ridge, alpha 10: базовый (нормированная сумма TRAIN gains и 8 бит компонента) и парный (плюс 28 pair indicators). Для каждой из 100 записей и двух TRAIN-доноров использовать все 8 одиночных и 20 случайно выбранных парных масок (seed=571), итого не более 100*2*28 = 5600 настоящих офлайновых модельных оценок, отдельно сохранять фактическое число пропусков при отсутствии доноров. Обучение получает только действительно измеренные target margin differences; TEST никогда не обновляет общий surrogate.

Методы при каждом Q: (1) прежний STATIC SPARSE BEACON, (2) PAIRS STATIC, (3) PAIRS ADAPTIVE, (4) ADDITIVE ADAPTIVE. Все используют одну и ту же модель, D1/D2, маски и support cap. Для ADAPTIVE после каждого реального модельного вызова обновляется только локальный posterior (initial covariance 0.25 I, noise 1.0), а не глобальная обученная модель. Фиксированный acquisition: maximin predicted target margin + exploration 0.25 sigma - support penalty 0.1. Никогда не возвращать результат без **двух реально измеренных** B для одной и той же компактной маски. Точный подсчёт каждого входа в общей Q, включая проверки минимальности.

**Единственная первичная парная гипотеза:** ADDITIVE ADAPTIVE против STATIC SPARSE при общем Q16 по J (одна маска, оба реально измеренных B, support не более 35% для каждого), все 320 заранее выбранных TEST в знаменателе. Разница долей, exact two-sided McNemar, alpha 0.05. Остальные сравнения и Q8 только разведочные, в том числе сравнение парного и аддитивного обучения.

Отчитываться о точности модели на всех 3498 TEST, offline-cost калибровки, локальной минимальности, wall-clock, исходных TEST-индексах и SHA данных/модели. Не делать выводов о глобальной минимальности, популяционной статистической устойчивости, точном SHAP или физически реалистичном написании цифры.
