# Замороженный протокол: BEACON / RacketSports / два донора / Q16

Дата фиксации: 21 ноября 2026 года. Эта спецификация коммитится **до загрузки RacketSports и анализа TEST**. Не изменять параметры после просмотра результатов, чтобы заявлять независимое подтверждение. При технических исправлениях, не меняющих научную постановку, сохранять протокол и отмечать исправление в SHA.

## Задача

Проверить отдельно от BasicMotions, подтверждается ли преимущество обратного удаления временных блоков перед прямым наращиванием по **совместной** метрике: целевой контрфакт непосредственно проверен, изменено не более 35% значений, а локальная несократимость по удалению одного блока доказана относительно данного донора. Второй критерий — сохраняется ли целевое предсказание при переносе *того же множества блоков* на другого, заранее выбранного TRAIN-донора класса B.

## Зафиксированные данные и классификатор

- Архив UEA RacketSports: официальный TRAIN=151, TEST=152, C=6, T=30, 4 класса (https://www.timeseriesclassification.com/description.php?Dataset=RacketSports).
- aeon.datasets.load_classification("RacketSports", split="train"/"test"); проверить точные размеры, конечность значений, метки и SHA сохранённого NPZ. Индексы классов определяются только TRAIN.
- Точное разделение по участникам в архиве не подтверждено. Не заявлять person-disjoint или причинность.
- Единственный **первичный** классификатор: ExtraTrees из scripts/run_clean_calibrated_staged_budget.py::fit_predictor с model="extratrees", seed=57, trees=120; стандартные настройки (скалер, инженерные признаки) из репозитория, исключительно TRAIN. Не дообучать и не выбирать модель по TEST.
- Оценить accuracy на всех TEST лишь в итоговом отчёте. При accuracy < 0.70 объявить убедительность объяснений классификатора недостаточной; не менять модель и не исключать окна.
- По всем 152 TEST окнам A — argmax логитов исходного предсказания, B — **фиксированный второй** класс. TEST-метки не участвуют ни в выборе B, ни в выборе донора, ни в поиске.

## Два независимых TRAIN-донора

- TRAIN-only банк: до 16 случайно выбранных TRAIN-окон на класс с seed=67, включает медоид (fit_real_donor_bank).
- До поиска на TEST проверить в модели, что сами доноры дают прогноз B; это **офлайновые TRAIN-проверки**, отдельно учитываются и не расходуют Q16 конкретного TEST-объяснения. Не подбирать банк по TEST.
- Для каждого TEST x из подходящих доноров предсказанного класса B выбрать **два разных** с наименьшей нормированной квадратичной дистанцией ко всему x; при равной дистанции — меньший TRAIN-index. D1 — первый; D2 — второй.
- Если модель предсказывает B менее чем для двух доноров банка, отметить «нет второго донора» и считать **0** по всем исходным и вторичным метрикам для этого окна; все 152 входят в знаменатель. Не заменять провальные окна.

## Сравниваемые методы (фиксированный Q16)

- Партия: 10 неперекрывающихся временных блоков [T=30] одновременно по шести архивным каналам; нет неподтверждённой физической интерпретации каналов.
- Оператор — текущий beaconxai.verified_counterfactual.splice, taper=2. Один выбранный донор для всех блоков объяснения; без смешения разных доноров.
- Порядок блоков: убывание abs(contrastive_prior), рассчитывается по TRAIN-профилям, фиксирован до первого модельного запроса. При равенствах — стабильный индекс.
- **FORWARD:** search_counterfactual_path, seed_singletons=3, max_changed_components=10, budget=16.
- **BACKWARD:** search_backward_counterfactual, порядок удаления — обратный дешёвому порядку, budget=16. Начальная полная замена отдельно проверяется; если она не переключает класс, объяснения нет.
- Для обоих методов оригинальные f(x) кэшированы и вынесены за бюджет; каждое новое модельное вычисление изменённого окна считается **одним Q**. Контроль: реальный счётчик вызовов совпадает с reported Q, а Q<=16.
- Два метода выполняются отдельно с D1 и с D2 (каждый запуск имеет свой Q16; два донора НЕ помещаются в общий Q16).
- Если алгоритм не нашёл целевой класс, возвращает отказ, а не неподтверждённое объяснение. Не использовать TEST-метки при принятии решений.

## Метрики и заранее заданный анализ

**Первичная, ровно одна парная гипотеза на TEST с D1:**
J = 1[model-confirmed B AND edited_fraction <= .35 AND local_minimality_checked] для BACKWARD против FORWARD; знаменатель 152. При отсутствии двух подходящих доноров — J=0 для обеих политик. Сравнивать разность средних J в процентных пунктах; двусторонний точный McNemar на discordant парах, alpha=0.05. Результат — с оценкой эффекта, числом discordant, точным p, без заявления причинной новизны.

**Вторичные и описательные:**
- Для D1/D2: target-flip coverage, fraction <=.20/.35/.50, locally minimal count, joint J, фактическая Q, медиана доли изменённых значений среди успехов.
- Независимый запуск BACKWARD на D2, доля успехов J2 среди всех 152 и среди D1-успехов, парные расхождения J1/J2, попарная Jaccard выбранных блоков среди случаев с обоими измеренными успешными контрфактами.
- **Контроль переноса**: для каждого подтверждённого D1 результата воспроизвести ТОЧНО ТЕ ЖЕ индексы блоков с D2 и сделать ровно один дополнительный вызов к чёрному ящику. Transfer validity = модель после такой замены снова предсказала B; соответствие порогу <=.35 фиксировать отдельно. Эти переносные проверки маркируются **OFFLINE AUDIT, +1 за успешное D1**, не считаются Q16 поисковой политики и НЕ подтверждают локальную минимальность на D2.
- Не использовать оценки D2, офлайновые переносы или TEST-метки для адаптации D1-поиска.

## Правила честной интерпретации

Различать объяснение модели и причинное описание реального движения. Подлинность атрибуции не доказана — проверяется только переключение **этого** чёрного ящика при указанных доноре и операторе. Не выдавать 1-deletion minimality за глобальную минимальность. В случае отрицательного/нулевого результата сохранить его; не менять Q, порог .35, seed, модель, размер групп, донора и TEST после просмотра. Учитывать предыдущую серию как разведочную, новую как независимый **корпус** (не гарантированно независимые участники). В отдельном отчёте задокументировать все зависимости, SHA модели, данных, исходных компонентов и исходный официальный split.
