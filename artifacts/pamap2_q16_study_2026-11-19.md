## Research question

Can a TRAIN-profile-based *contrastive shortlist* followed by only 16 additional
black-box model evaluations localize an artificially replaced time-series
component better than uniform selection, a zero-query prior, and 16-query
mask-regression controls? Separately: does it improve targeted A -> B
single-patch class-switch probes?

This new `contrastive_q16` algorithm is **NOT** the published `adaptive_v2`
algorithm and must not be described as a direct reproduction of it.

## Dataset and protocol

- UCI PAMAP2, DOI 10.24432/C5NW2H; official 656 MB archive processed with repository's `preprocess_pamap2.py`.
- Nine 3-axis accelerometer channels, windows of length 200, step 100, purity >= .95.
- Subjects 8 and 9 are held out for testing; all class prototypes are computed from training data only.
- ExtraTrees with 120 estimators on the repository's engineered `_anfis_features`; scores are log predicted probabilities.
- Three sensor groups * twelve time bins = **36 components**.
- Reproducible random subset of 128 test windows; half receive one patch from an example of another class, randomly placed in a component (**64 injected windows**).
- Five methods, three seeded repetitions; four methods get 16 **additional** model evaluations, while `prior_q0` uses none; original prediction is shared/cached.
- Synthetic-patch localization `hit@3` is the primary endpoint. It is not classification accuracy, physical causality, or verified class feature relevance.

## Results — artificially injected component localization

| Method | Additional calls | hit@1 | hit@3 | hit@5 | MRR |
|---|---:|---:|---:|---:|---:|
| **Contrastive preselection + occlusion** | **16** | **0.3021** | **0.4219** | **0.4792** | **0.3956** |
| Cheap TRAIN class-profile ranking alone | 0 | 0.2656 | 0.3125 | 0.3281 | 0.3291 |
| RISE-like masking + ridge regression | 16 | 0.1406 | 0.2344 | 0.3021 | 0.2434 |
| Uniform component occlusion | 16 | 0.1458 | 0.2292 | 0.2604 | 0.2222 |
| KernelSHAP-like weighted ridge regression | 16 | 0.0729 | 0.1146 | 0.1563 | 0.1532 |

At N=64 injected test windows, mean hit@3 by seed (contrastive): 0.4375, 0.4062, 0.4219.
`prior_q0` is deterministic for these examples (0.3125 each repetition).

Paired *window-level* bootstrap (three repetitions first averaged per test window,
then 20,000 resamples; sample dependence NOT corrected):

| Contrastive minus comparator | Delta hit@3 | exploratory 95% interval |
|---|---:|---:|
| Uniform Q16 | +0.1927 | [+0.0988, +0.2865] |
| Zero-query prior | +0.1094 | [+0.0208, +0.1979] |
| RISE-like Q16 | +0.1875 | [+0.0729, +0.3021] |
| KernelSHAP-like Q16 | +0.3073 | [+0.1823, +0.4323] |

**DO NOT interpret these intervals as population-level significance:** windows overlap
and only two participants are held out. Multiple method comparisons were not
corrected here; cross-subject folds and uncertainty analysis are required.

## Targeted A -> B local decision probe (separate task)

112 correctly classified held-out windows were subjected to one-at-a-time
class-B TRAIN-mean patch replacement (same 16-query budget and operator for
the two selection strategies), three repetitions.

| Selection | Target-class flip rate | Mean maximum reduction of fixed A-B score gap |
|---|---:|---:|
| Contrastive | 0.0833 | 0.4811 |
| Uniform | 0.0744 | 0.4396 |

Paired per-window bootstrap:
- Flip rate delta = +0.00893; exploratory 95% interval [-0.00893, +0.02976].
  **No defensible advantage in actual class switching.**
- Best gap reduction delta = +0.04150; exploratory 95% interval [+0.01404, +0.07081].
  This is a model-score effect, NOT a physically validated transition to another
  activity or recovery of class boundaries.

These class-pair probes used the model's predicted top class versus a runner-up
or fixed target. The study is **not** a dedicated walking-versus-running test.

## Computational audit

- Each additional model evaluation is counted for Q=16, even when vectorized.
- **Timing is not currently a fair wall-clock comparison:** contrastive and uniform
  use sequential single-sample prediction (approximately 142 ms for 16 checks),
  whereas RISE/KernelSHAP-like mask regressions use one batch prediction
  (approximately 13 ms on this GitHub runner).
- The `prior_q0` reported time excludes computing the class-profile scores
  because it reuses the prior from the contrastive method; **do not cite it
  as the true stand-alone zero-query runtime**.
- TRAIN class means + variances in float64 cost 345,600 bytes (337.5 KiB)
  for twelve classes, 200 points and nine channels, before the classifier.
  CPU, memory, and energy on actual microcontrollers remain untested.
- RISE-like is **not canonical RISE**, and KernelSHAP-like is **not exact SHAP**.
  At M=36 and Q=16, regression of 36 feature coefficients (plus intercept)
  on 17 mask observations including cached baseline is underdetermined;
  ridge regularization heavily influences inferred ranks.
- Data manifest SHA256 of prepared NPZ:
  `93dcc4196b078ec84b1d93048148043d86dc7be04528fb009cb879a3509b9ca3`.

## Interpretation for the scientific claim

1. **Positive, narrow result:** under this artificial-injection test, the
   class-profile-guided Q16 prototype ranks changed components above uniform
   and the implemented 16-query mask-regression controls.
2. **Relevant ablation:** zero-query class-profile ranking already reaches
   31.25% hit@3; 16 model probes add ~10.94 percentage points in this setting.
   Thus a large part of performance comes from train-set class structure.
3. **Negative result:** target-class flip probability is not convincingly
   improved, so class-boundary explanation is not established.
4. These results do **not** demonstrate superiority over LIME/LIMESegment,
   original RISE, official KernelSHAP, TreeSHAP, Dynamask, or the published
   `adaptive_v2` until matched implementations and protocols are added.
5. Prior repo v12 finds adaptive early stopping reduces query budgets without
   a verified equal-budget risk-quality gain across HAR, PAMAP2, WISDM;
   this is separate from the new localizer experiment.

## Next falsifiable tests (ordered)

1. Compare the *original adaptive_v2 combined* and a zero-query energy/variance
   prior on the **same** injected samples, fixed model, Q16, componentization
   and perturbation operator.
2. Establish equal-cost timings: either batch all methods or execute them all
   sequentially; measure full prior-computation cost and memory, not calls alone.
3. Repeat with multiple subject-level folds (prefer leave-one-subject-out).
   Use subject-blocked or time-blocked inference and report per-subject effects.
4. Test several perturbations (interpolation, zero, class mean, plausible
   donor-based) and distinguish synthetic-patch detection from natural feature
   importance.
5. Only after (1)-(4), build class-conditional prototype/rule explanations and
   compare to LIMESegment, rule extraction for ExtraTrees, and specialized
   temporal explanation baselines.

## Reproduction

```bash
python scripts/preprocess_pamap2.py --data-root data --window-length 200 --step 100 --min-purity 0.95 --test-subjects 8,9 --out data/pamap2_acc9_w200s100_p095.npz
python scripts/run_contrastive_q16.py --mode both --time-bins 12 --group-mode pamap3 --budget 16 --max-test 128 --repeats 3 --seed 42
```

The original 24-component ~46.09% result and this new 36-component 42.19%
result are **different experiments**; they must not be pooled or treated as
paired evidence.
