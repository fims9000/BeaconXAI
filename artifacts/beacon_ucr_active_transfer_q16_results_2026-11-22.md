## Вопрос и схема

Контрфактическая маска S считается подтвержденной online только при действительно измеренном target B на **двух** TRAIN-fit донорах D1,D2, доле фактически измененных координат ≤35% на каждом и **одном общем Q16** с учетом непрошедших кандидатов и проверок удаления блоков. Проверка той же S на D3,D4 осуществляется строго **после** остановки алгоритма, отдельными модельными запросами, никогда не влияет на выбор маски и не называется сертификатом в Q16. B фиксирован как runner-up на исходном f(x); истинные TEST-метки используются только для accuracy.

Три стратегии используют тот же самый search_sparse_robust_counterfactual:
1. **STATIC SPARSE:** исходный TRAIN-profile maximin по 10 временным блокам;
2. **LEARNED STATIC:** обученная на TRAIN вероятность совместного реального переключения на D1,D2,D3,D4 используется только для начального ранжирования кандидатов;
3. **LEARNED ONLINE:** тот же TRAIN-fitted score обновляется после фактически измеренных D1/D2 probe с помощью фиксированного similarity-feedback по симметрической разности масок (влияние дополнительных запросов за пределами Q равно нулю).

TRAIN-суррогат обучен на контролируемых 20 масках каждого отдельного TRAIN ranking-fit окна (10 одиночных, 5 парных, 5 тройных), с проверкой TRAIN доноров и остановкой на первом реальном отказе. StandardScaler + balanced LogisticRegression, C=1, seed57, гиперпараметры не подбирались на TEST. Две непересекающиеся TRAIN части выделены для обучения ранжирования и независимой offline-валидации AUC. Всего 25 признаков, доступных до вмешательства: размеры/позиции маски, D1/D2 реальные edit fractions, TRAIN gains, парные MSE доноров и исходный target margin. **Признаки никогда не используют D3/D4, их измеренные outcomes или TEST labels.**

## Первичный UCR Wafer — подтвержденный положительный эффект

Wafer: реальные сенсорные измерения процесса изготовления полупроводниковых пластин. Официальные TRAIN 1000, TEST 6164, один канал, T=152, два неравновесных класса; Q16 на 320 TEST индексах, выбранных **только по seed5744**. Модель ExtraTrees seed57/trees120, только TRAIN-fit: **98.1668% accuracy на полном TEST**, заранее заданный порог качества 70% выдержан. Нет подтвержденных ID приборов/партий, поэтому нельзя заявлять независимость по оборудованию.

| Метод | K2 подтверждений из 320 | Та же маска прошла невиданных D3+D4 | Условная доля среди K2 | Среднее Q16 | 1-deletion локальная минимальность |
|---|---:|---:|---:|---:|---:|
| Исходный STATIC SPARSE | 94 | **44/320 (13.75%)** | 44/94 = 46.81% | 13.928 | 86 |
| LEARNED STATIC | 148 | **58/320 (18.125%)** | 58/148 = 39.19% | 13.063 | 137 |
| **LEARNED ONLINE** | 148 | **58/320 (18.125%)** | 58/148 = 39.19% | 12.950 | 136 |

**Заранее определенное первичное сравнение:** LEARNED ONLINE − STATIC SPARSE по **безусловному** J4: оба успешны 40 окон, только LEARNED ONLINE — 18, только исходный — 4, оба не дали transfer — 258. Разница **+14/320 = +4.375 процентного пункта**, exact two-sided McNemar **p=0.0043435097**. Описательный paired bootstrap по 320 архивным окнам (10k повторений, seed57): 95% percentile **[+1.5625, +7.1875] п.п.**. Такой интервал НЕ гарантирует перенос на новые производственные машины/партии, потому что их IDs неизвестны.

Критический вывод абляции: **обученный статический и обученный онлайн-поиск одинаковы по общему J4 — 58/320**. Хотя совпадения не полные (57 общих, по одному уникальному успеху каждого, exact McNemar p=1.0), поддерживающих данных за дополнительную пользу **динамического feedback** нет. Успех по J4 объясняется прежде всего сильнее обученным **начальным ранжированием масок** по TRAIN-контрфактам.

Еще одно ограничение: среди найденных K2 сертификатов условная переносимость **снизилась** с 46.8% до 39.2%. Улучшение относится только к числу переносимых масок **на всю тестовую выборку**, за счет роста числа K2 сертификатов. Это не повышение надежности любого отдельного выданного объяснения.

Выраженная неравномерность по исходному предсказанному классу: в фиксированных 320 TEST источники были 30/290. Для меньшей группы J4 вырос 26→27, для большей — **18→31**. Поэтому эффект может зависеть от направленности контрфакта и дисбаланса классов. Персональные/аппаратные разбиения и устойчивость при иной модели не доказаны.

TRAIN candidate prior: 2980 измеренных масок, **159 положительных** по совместному D1..D4 критерию (5.34%); на независимых 3040 TRAIN-calibration масках **129 положительных**, AUC **0.83117**, Average Precision **0.18207**. Это подтверждает определенную предсказательную ценность cheap ranking для Wafer (не калиброванную вероятность успеха на любых будущих донорах).

## Репликация UCR TwoPatterns — численный эффект без подтверждения и с неадекватной моделью

TwoPatterns: искусственный univariate временной ряд (TRAIN 1000, TEST 4000, T128, K4), фиксированная TEST-подвыборка 320 из перестановки seed5755. Та же архитектура ExtraTrees и **точно те же** seed, маски, 35%, Q16, обучающее правило и веса feedback, никаких подстроек после Wafer.

Модель достигла **35.725% accuracy на полном TEST** — ниже заранее установленного 70%-порога и ненамного выше случайного 25% для четырех классов. Следовательно, успехи объяснения **нельзя интерпретировать как объяснение качественного классификатора**.

| Метод | K2 сертификаты из 320 | Перенос D3+D4 из 320 | Среднее Q16 |
|---|---:|---:|---:|
| STATIC SPARSE | 163 | 49 (15.313%) | 13.291 |
| LEARNED STATIC | 158 | 49 (15.313%) | 12.931 |
| LEARNED ONLINE | 171 | 54 (16.875%) | 12.825 |

Для LEARNED ONLINE против STATIC: оба 32, online-only 22, static-only 17, разница **+5/320 = +1.5625 п.п.**, exact McNemar **p=0.52240**. **Доказанного улучшения нет**, репликация не усиливает общий вывод. LEARNED ONLINE против LEARNED STATIC: 54 против 49, p=0.30176 — тоже без доказанной пользы feedback.

На независимой TRAIN-калибровке качества приоритета всего AUC **0.51842**, AP 0.06506 — практически отсутствует различающая способность, в отличие от Wafer. Отрицательный результат сохранен неизменным, TEST параметры не адаптированы.

## Корректный научный вывод

На Wafer впервые за эту линию разработок получено **улучшение безусловной доли объяснений, переносимых на ранее не виденных во время поиска донорах**, по заранее выбранному парному тесту. Однако:
- она достигнута для одного фиксированного двухклассового корпуса и одной ExtraTrees;
- **не подтверждена дополнительная ценность адаптации после запросов**, поскольку LEARNED STATIC дал ровно те же 58 случаев; выбирать сложный вариант как обязательный нет оснований;
- условная надежность уже выданных объяснений снизилась; это не сертификат на произвольных донорах или на другой популяции;
- офлайновая стоимость построения меток около 7.4k модельных входов и дополнительное CPU время существенны;
- на TwoPatterns как тесте переноса гипотеза не получила поддержку и качество самого классификатора не прошло preregistered adequacy gate.

Рабочее направление: **TRAIN-fitted static joint-mask ranking** как кандидат на экономный Q16 search, с исходным STATIC SPARSE обязательным baseline. Динамический feedback остается исследовательской абляцией. Для следующей статьи нужны повторение на качественных моделях и корпусы с реальными donor-identity / context controls, сильные внешние counterfactual baselines с честной стоимостью и операторная правдоподобность. **Не переносить в main и не заявлять общего превосходства над XAI SOTA.**
