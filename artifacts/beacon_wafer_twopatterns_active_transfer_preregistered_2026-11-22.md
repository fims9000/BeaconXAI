# BEACON — заранее зафиксированный эксперимент: обучение переносимого ранжирования и адаптивный выбор масок при Q16

Дата: 22 ноября 2026 г. **Фиксация до загрузки официальных TEST для Wafer и TwoPatterns.** CharacterTrajectories, SpokenArabicDigits, UWave, PenDigits, NATOPS, Epilepsy и RacketSports уже просмотрены и не могут использоваться как новые независимые holdout.

## Главная гипотеза

Предыдущий train-fit риск-фильтр отказал только в одном дополнительном случае и не повысил безусловный перенос. Простая фильтрация уже найденной маски не может увеличить число успешных переносов. Здесь **впервые до запросов модели выбираем саму маску с учетом TRAIN-оценки совместного успеха на новых донорах**. Дополнительный вариант динамически меняет выбор оставшихся масок на основании реально полученных внутри Q16 ответов. Никаких оценок D3/D4 не видно онлайн ни одному варианту.

## Независимые корпуса

Основной пререгистрированный результат: UCR **Wafer**, официальный TRAIN 1000, TEST 6164, одна сенсорная временная координата, длина 152, два класса. Отдельная репликация при тех же параметрах: UCR **TwoPatterns**, TRAIN 1000, TEST 4000, одна временная координата, длина 128, четыре класса; синтетические данные, не физическое воздействие. Архивная загрузка только aeon==1.5.0, строго проверять размеры и классы. Не подменять версию/разбиение. При другой форме остановить до inference, оформить техническое отклонение отдельно.

В каждом корпусе независимо разделить официальный TRAIN стратифицированно (seed=57): 70% каждого класса в model-fit, floor(15%) в offline ranking-fit, остальные в ranking-calibration. Никакой общности записей между частями. Нормировка, профили и donor bank только по model-fit; frozen ExtraTrees из fit_predictor, trees=120, seed=57, без подбора по TEST. Порог пригодности accuracy на полном TEST 70%; если хуже, нельзя делать сильный научный вывод. TRAIN / TEST идентификаторы физических приборов не проверены, не заявлять device-level независимость.

Ровно 320 TEST окон для объяснений выбираются только по заранее заданной перестановке индексов seed=5744 для Wafer и seed=5755 для TwoPatterns, отсортированный первый блок из 320. Все исходные f(x) для **полного** TEST посчитать и отдельно включить в стоимость; TEST-метки только для accuracy. Выбрав корпус, параметры не менять по результатам предыдущего из двух тестов.

## Доноры и сохраняемые ограничения

На каждом x фиксируются A=argmax исходного ответа модели, B=runner-up. TRAIN-fit bank до 16 записей на класс, seed=67, label model-confirmed B после отдельно оплаченного screening. D1,D2 — два ближайших к x TRAIN примера B по стандартизованной MSE; D3,D4 — два ближайших *после* D1,D2, строго вне онлайн-поиска и выбора маски. Если менее четырех eligible, все варианты дают J=0, этот x остается в общем N=320.

Оператор: 10 непересекающихся последовательных all-channel блоков, taper=2, максимум реально измененных координат 35% **для каждого** проверяемого донора. **Q=16 на D1+D2 суммарно** для всех методов, включая prunes, ошибки и проверку сокращения. Включать только подтвержденный argmax=B на обоих online-донорах **одной маски**. D3/D4 проверять для той же готовой S **после** поиска, за отдельные точно измеренные model calls. Ни один результат на D3/D4 не входит в Q16 или ранжирование на TEST.

## TRAIN-only обучение дешевого предиктора совместного успеха

В ranking-fit для каждого окна при наличии четырех TRAIN-confirmed доноров: фиксированный набор 20 кандидатов — 10 одиночных блоков, 5 пар и 5 троек, пары/тройки выбираются без повторений генератором seed=7714. Отбросить кандидатов, которые изменяют >35% значений на D1 либо D2. Фиксировать фактическую поддержку по D1/D2 до всяких вызовов модели. Для каждого оставшегося кандидата получить настоящие f(T_S(x,d)) последовательно на D1,D2,D3,D4, остановившись на первом нарушении argmax=B или поддержки ≤35% (последняя проверка может быть сделана без модельного вызова). Целевая метка TRAIN: 1 **только при успешном измеренном переключении на всех четырех донорах**, иначе 0. Эти офлайновые обращения к модели не бесплатны, сохранять их полное число.

Признаки кандидата вычисляются **только** из x, f(x), пары D1,D2, TRAIN class-profiles и выбранной S (никаких D3/D4): количество выбранных блоков, 10 бинарных индикаторов, средняя и максимальная доля изменений, min/mean/spread суммы cheap TRAIN gains, min/max/mean одноэлементных gains, MSE x↔D1, x↔D2 и D1↔D2, исходный target-vs-rest margin, индекс центра маски, число соседних пар (без физического смысла). Запрет на TEST labels, donor-D3/D4 геометрию и любые реальные TEST-измерения при обучении.

Обучить StandardScaler + LogisticRegression(C=1, class_weight="balanced", solver="liblinear", random_state=57, max_iter=600) на ranking-fit; если одна целевая метка, честно использовать constant Laplace. На независимом ranking-calibration вычислить accuracy ранжирования и AUROC для TRAIN-only оценки обобщения (это отдельный технический endpoint, без гиперпараметрического подбора). Не подбирать новую формулу после TEST. Калибровка не меняет модель, а публикуется как sanity-check; это *предиктор приоритета*, не модельно подтвержденный сертификат.

## Сравниваемые алгоритмы — одно существующее ядро поиска

Не копировать search_sparse_robust_counterfactual. Добавить к нему необязательную callback-политику сортировки компактных масок; без callback точное поведение старого метода должно оставаться неизменным. Прямые вызовы модели, кэш, поддержка, порядок проверки доноров, pruning и формирование сертификата одинаковы.

1. STATIC SPARSE: исходный robust maximin TRAIN profile scorer, без callback.
2. LEARNED STATIC: кандидаты сортируются убыванием TRAIN-fitted вероятности совместного успеха J4; во время Q16 порядок не меняется.
3. LEARNED ONLINE: после каждого полностью/частично проверенного кандидата обновлять динамический score оставшихся масок, но **не менять обученную логистику на TEST**. Для маски S: logit(p_TRAIN(S)) + 2.0/num(probes) * sum over measured probes [(2*flip−1)*exp(−|S symmetric_difference Sprobe|/1.5)]. Если probes=0, добавка 0. Учитывать только фактически измеренные ответы D1/D2, включая неуспехи. Deterministic tie-break по меньшему индексу маски после сортировки; не расходовать отдельные model calls на пересчет приоритета. Ошибочные/непроверенные D3/D4 online не доступны.

Во всех трех методах подлинный J2 сертификат зависит только от реального argmax model on D1,D2. Нет гарантии J4, пока не измерены D3/D4 отдельно.

## Первичная метрика и прочие диагностические измерения

**Одна первичная парная гипотеза на Wafer:** LEARNED ONLINE против STATIC SPARSE, безусловный J4=1 при реально подтвержденной компактной маске в общем Q16 для D1,D2 плюс измеренном переносе **той же маски** на D3,D4. Все 320 тестовых записей в знаменателе; двусторонний exact McNemar, alpha=.05. **TwoPatterns** — заранее замороженная replication/secondary; p считать отдельно, не объявлять независимой второй подтверждающей первичной проверкой. Также показать J2, conditional J4 transfer среди J2 success, D3/D4 edit supports, локальную минимальность, средний/максимальный Q, CPU wall-clock, отказ/availability donor bank.

По возможности разложить улучшение на эффект TRAIN learned ranking (learned static) и реального онлайн feedback (learned online). Если LEARNED ONLINE не имеет подтвержденного превосходства и/или не переносится на другом корпусе, честно сохранить отрицательный результат. Не использовать TEST для изменения коэффициентов, квантилей или другого порога.

Каждый model-input evaluation в fit/ranking-calibration/online/audit считать отдельно, сохранять CSV всех 960 TEST запусков на каждый корпус, manifest.json (TRAIN split indices, TEST selected indices, SHA data/model/scaler, learned coefficients, query accounting, offline calibration labels, data provenance), summary.csv, provenance.txt и GitHub Actions run. TEST не гарантирован disjoint по физическим приборам/пациентам или писавшим людям; Wafer и TwoPatterns — разные данные, не сравнивать их сырые доли без оговорок. Существующая Part 1/2 и main не изменяются.
