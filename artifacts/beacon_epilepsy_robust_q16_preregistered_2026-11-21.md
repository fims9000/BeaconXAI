# Замороженный протокол: двухдонорные контрфакты BEACON, общий Q16, UEA Epilepsy

Дата фиксации: 21 ноября 2026 г. Этот документ коммитится **до загрузки TEST и получения результата**. Алгоритм и сравнение разработаны по прежним UCI HAR, BasicMotions и RacketSports; ни одного результата Epilepsy для настройки не использовать. После просмотра Epilepsy TEST не менять Q, порог, модель, доноров, порядок, гранулярность или основную метрику. Исправления ошибок должны сохранять смысл протокола и иметь новый SHA.

## Данные и интерпретация

- Официальный UEA Epilepsy: 137 TRAIN, 138 TEST, 3 канала, 206 временных отсчётов, 4 класса. Источник `aeon.datasets.load_classification("Epilepsy", split="train"/"test")`, пакет aeon 1.5.0, оригинальные разбиения.
- Архив описывает движения с имитацией эпилептического приступа, не медицинские диагнозы. Источники [UEA table](https://www.mdpi.com/1424-8220/25/5/1487) и [dataset documentation](https://galilai-group.github.io/stable-datasets/datasets/epilepsy/). Не делать медицинских выводов.
- В документации описан разделённый по участникам протокол (3 TRAIN / 3 TEST), но точные IDs отдельных окон не находятся в массиве. Отдельно записать отличие документированного разбиения от независимо проверенного participant-ID overlap.
- Проверять форму, отсутствие пропусков, число классов, SHA данных. Кодирование меток строится только по TRAIN. TEST-метки разрешены исключительно в финальной оценке классификации.
- Строго TRAIN-only нормировка и fit_predictor(..., model="extratrees", seed=57, trees=120). Если TEST accuracy менее 70%, не заявлять хорошее объяснение качественной модели и не менять классификатор.
- На всех 138 TEST окнах источник A = исходный argmax, цель B = второй по вероятности класс замороженной модели (никогда не истинная TEST-метка).

## TRAIN-доноры и оператор

- TRAIN-only банк fit_real_donor_bank, максимум 16 доноров каждого класса, seed=67. Проверить моделью предсказанный класс каждого TRAIN-донора, **отдельно оплаченная офлайновая TRAIN-классификация**.
- Из предсказанных моделью доноров класса B заранее выбрать два разных TRAIN-index с минимальным средним квадратом разности со стандартизованным x, tie-break меньший TRAIN-index. Если нет двух, все методы получают 0 по строгой метрике на этом окне, без исключения из знаменателя.
- Десять неперекрывающихся временных интервалов по всем 3 каналам, `make_components((206,3),10,"all_channels")`; индексные границы из текущего метода, без трактовки как биомеханический закон.
- Один оператор `splice(...,taper=2)` и один и тот же TRAIN-only порядок блоков по `abs(contrastive_prior)`, стабильные равенства. Для удаления — обратный порядок (сначала менее значимые).

## Методы, каждый имеет ровно ОДИН общий лимит Q=16

1. **НОВЫЙ, backward robust chunk pruning:** начать с полной маски, проверить её на D1 и D2 за два настоящих модельных обращения. Если хотя бы один не даёт B — отказ. Далее удалять группы блоков по детерминированному крупному→мелкому разбиению (начальный chunk=floor(10/2)=5, затем при отсутствии успехов chunk=floor(chunk/2), до единицы), принимая удаление только после прямого подтверждения B на **обоих** донорах. Не возвращать частично проверенную маску. Все проверки входят в Q16; кеширование допускается только идентичной пары (маска, донор). Проверенная 1-deletion минимальность заявляется только при полном отрицательном сканировании каждого удаления из финальной маски.
2. **POSTHOC контроль при том же общем Q16:** обычный `search_backward_counterfactual` на D1 с бюджетом максимум 15; если нашёл B, выполнить ровно **один дополнительный запрос D2 с той же маской**. Сертификат двух доноров только при реально полученном B от D2. Дополнительный запрос входит в общий Q16. Выданная локальная минимальность D1 НЕ является минимальностью на D2.
3. **Существующий FORWARD robust** как второй контроль: `search_robust_counterfactual` для двух доноров, Q16, max_changed_components=10, seed_singletons=1, prune=True, те же компоненты и тот же порядок. Никакого отдельного Q16 на каждого донора.

Любое подтверждение — это только модельное переключение **на двух выбранных TRAIN-донорных реализациях одной маски**, не гарантия для невиденных доноров, распределения, причинности или физических ограничений.

## Фиксированные метрики и сравнение

**Одна основная парная гипотеза:** для каждого из 138 TEST окон J=1, если *одна и та же маска* непосредственно измеренно переключает исходную модель в B **на D1 и D2**, и оба сигнала имеют изменённую долю значений <=0.35. Сравнить NEW backward robust против POSTHOC D1 + D2 audit, разницу долей, discordant пары и двусторонний точный критерий Мак-Немара (alpha 0.05). Без найденных доноров J=0. Не требовать локальной минимальности в J: при двух донорах проверка маски и каждого её сокращения при Q16 может математически не помещаться в бюджет.

Вторичные, описательные: точные Q расходы каждого метода, кол-во модельно подтверждённых двухдонорных масок независимо от размера, пороги 20/35/50%, проверенная 1-deletion минимальность по обоим донорам (только если все однокомпонентные удаления действительно отвергнуты), донорные различия в долях редактирования, неудачи начальной полной маски, доля случаев без двух подходящих TRAIN-доноров. Отдельный отчёт о classifier accuracy, SHA модели/скалера/данных, разбиении, версиях, CSV для каждой записи.

**Не менять протокол после результатов.** Величина p не доказывает причинность или универсальность и должна интерпретироваться с учётом многочисленных предшествующих разведочных экспериментов по другим наборам. Тестируем только новую пару методов и заранее выбранную строгую метрику на новом корпусе. `main` и существующие результаты RacketSports не изменять.
