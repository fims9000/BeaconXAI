# BEACON: независимая проверка адаптивного Q8/Q16 на PenDigits с raw MLP

Дата: 22 ноября 2026 года. **Завершённый результат: положительное численное изменение, но первичная гипотеза не подтвердилась статистически.** Попарная модель не получила преимущества над более простой аддитивной.

[Исходный протокол, зафиксированный до доступа к PenDigits TEST](beacon_pendigits_additive_adaptive_preregistered_2026-11-22.md), commit 47876dba06b0753413c854d56d8040146aef6e4f. [Полный успешный GitHub Actions 44950732585](https://github.com/fims9000/BeaconXAI/actions/runs/44950732585), CSV/JSON доступны в артефакте.

## Данные и независимое обучение

Официальный UEA PenDigits, 7494 TRAIN, 3498 TEST, две координаты рукописного штриха, 8 отсчётов, 10 цифр. TRAIN-only разбиение seed 57: 7394 записей обучают замороженную **raw MLP** из существующего fit_predictor (32 скрытых нейрона, max_iter 30, early stopping), ровно 100 записей (по десять на класс) калибруют оценки фрагментов. Нет общих окон между trainfit/calibration, но идентификаторы людей между официальными TRAIN/TEST недоступны.

**TEST accuracy raw MLP на всех 3498 = 94,768% (3315/3498)**; заранее заданный порог 70% соблюдён. Поиск объяснений производился на заранее выбранных **320** индексах TEST (перестановка seed 5712, индексы сохранены в manifest). Эту выборку нельзя называть всеми 3498 наблюдениями или новыми независимыми людьми.

Для каждого источника x фиксируются предсказанный исходный класс A, следующий по лог-оценке B, два TRAIN-донорных окна B, заранее модельно подтверждённых. Оператор: восемь точек рукописного штриха по двум каналам, отсутствие taper, не более 35% реально изменённых координат для каждого из доноров. Это математически проверяемое вмешательство в данные, но **не реальное причинное переписывание цифры**. Сертификат только при настоящем переключении класса B на D1 и D2 с **общим Q8 или Q16**.

Два TRAIN-only Ridge суррогата: сумма 8 статистических влияний / одноэлементные indicators (аддитивный) и дополнительно 28 индикаторов пар (попарный). Ровно 5600 offline модельных оценок на калибровочных одиночных/парных масках, плюс 100 исходных калибровочных и 160 скрининговых донорных оценок. In-sample MAE: PAIRS 1,3920, ADDITIVE 1,3938; небольшая разница не доказывает переносимость pairwise. После каждого онлайн измерения posterior корректируется только для текущего окна, глобальные веса от TEST не обучаются.

## Прямое двухдонорное подтверждение с поддержкой ≤35%

| Метод | Q8 на 320 окнах | Q16 на 320 окнах | Q16: поддержка ≤20% | Локальная 1-deletion минимальность подтверждена | Среднее модельное Q16 |
|---|---:|---:|---:|---:|---:|
| STATIC SPARSE BEACON | 232 | 252 | 127 | 246 | **8,62** |
| PAIRS STATIC | 240 | 256 | 129 | 251 | 9,39 |
| PAIRS ADAPTIVE | 242 | 257 | 132 | 254 | 9,18 |
| ADDITIVE ADAPTIVE | **242** | **257** | **133** | 253 | 8,94 |

**Заранее установленная первичная пара:** ADDITIVE ADAPTIVE против STATIC SPARSE, Q16, все 320 отобранных окон.

- Оба метода успешны: 251.
- Успех только ADDITIVE: 6.
- Успех только STATIC: 1.
- Оба не нашли сертификат: 62.
- Абсолютная разница = 5/320 = **+1,5625 п.п.**
- Двусторонний точный Мак-Немар = **p=0,125**; при alpha 0.05 значимое улучшение **не подтверждено**.

Q8: ADDITIVE ADAPTIVE 242 против 232 STATIC, точный p≈0,05248 (исследовательское сравнение, не первичная гипотеза). PAIRS ADAPTIVE и ADDITIVE ADAPTIVE при Q16 оба дают 257/320, на каждой из трёх парных ошибочных перестановок друг друга; точный парный p=1,0. У более сложной модели нет преимущества.

## Перенос на неучаствовавшие D3 и D4

Каждую успешно найденную при Q16 маску применили после завершения поиска к двум другим TRAIN-донорам, вне онлайн Q. Проверка оплачена отдельно.

| Метод | D1+D2 успехи | Та же маска успешна на D3+D4 | Доля среди D1+D2 успехов |
|---|---:|---:|---:|
| STATIC SPARSE | 252 | 158 | 62,7% |
| PAIRS STATIC | 256 | 150 | 58,6% |
| PAIRS ADAPTIVE | 257 | 149 | 58,0% |
| ADDITIVE ADAPTIVE | 257 | 150 | 58,4% |

Перенос выбранных масок **хуже**, чем у статического контроля. Увеличение охвата D1+D2 не доказало выявление более инвариантных механизмов. Сигнал из другого рукописного жеста может создавать недопустимую склейку и не даёт физического причинного объяснения.

## Научный вывод

На этом корпусе с **хорошей raw MLP (94,77%)** адаптивные методы достигли 257/320 против 252/320 у статического BEACON, что является небольшим и статистически неубедительным преимуществом. Сравнение не воспроизвело достаточный эффект UWave, где объясняемая ExtraTrees имела accuracy только 62,2%.

На двух новых корпусах обучаемая попарная модель **не оправдала 45/28 дополнительных параметров** и дополнительные offline измерения. Наиболее обоснованная рабочая версия — простая ADDITIVE ADAPTIVE, но даже для неё не доказано улучшение устойчивости относительно новых доноров. Результат при Q16 не следует превращать в утверждение о причинном объяснении или обобщённом превосходстве XAI.

Следующее исследование должно перейти от метрики D1+D2 к проверке сохранения тех же фрагментов на новых донорах и к операторам, которые допустимы для конкретного датчика. В дальнейшем нужен корректный внешний benchmark против действующих современных CF-методов при одинаковых требованиях к реальности вмешательства и честной полной стоимости.
