## Данные, модель, бюджет

Источник и параметры класса B: B — исходно предсказанный второй класс фиксированного классификатора, никогда не TEST-метка. Первичный ExtraTrees, seed=57, 120 деревьев, обучен только по TRAIN. Тестовая accuracy — **125/152 = 82.24%**; зафиксированный перед экспериментом критерий ≥70% соблюдён.

Для каждого окна два разных модельно подтверждённых TRAIN-донора B: D1 — ближайший, D2 — второй ближайший по нормированному среднеквадратичному расстоянию между полными временными рядами. Отбор до поиска, без TEST-разметки. Во всех 152 окнах найдены оба подходящих донора.

Оператор: 10 неперекрывающихся временных блоков, одновременно по всем шести каналам, с taper=2; физическая допустимость не гарантируется. Два Q16 алгоритма: forward-growing с 3 отдельными стартовыми проверками и backward-pruning от предварительно проверенной полной донорской замены. Порядок из TRAIN-классовых профилей, для backward — обратный. **Оригинальный ответ f(x) кэширован; каждое новое обращение с кандидатом считается отдельным Q.**

Сырые данные, исполнение и полный отчет CI: https://github.com/fims9000/BeaconXAI/actions/runs/44936391554 . Завершение: SUCCESS; 24 целевых теста PASS; все 152 записи обработаны. ## Первичная гипотеза: отрицательная

Предварительно зафиксированное бинарное событие:

J = [модель непосредственно подтвердила целевой B] И [изменено <=35% значений] И [для финальной маски реально проверена 1-deletion минимальность относительно фиксированного донора и 10 блоков].

Первичная сравниваемая пара — FORWARD(D1) и BACKWARD(D1). Все 152 тестовых окна в знаменателе, без отбрасывания неудачных классов, доноров или окон.

| Показатель при D1 и не более Q16 | FORWARD | BACKWARD |
| --- | ---: | ---: |
| Непосредственно подтверждённые переходы в B | 103/152 | 98/152 |
| Подтверждённые B при изменении <=35% | 75/152 | 76/152 |
| Подтверждённые B с проверенной локальной 1-deletion минимальностью | 80/152 | 86/152 |
| **Все три требования одновременно (J)** | **71/152** | **71/152** |
| Среднее число онлайн-вызовов модели | 8.58 | 8.08 |
| Медиана доли изменений среди успешных B | 20% | 20% |

Парная таблица для J: оба метода 68, только обратный 3, только прямой 3, ни один 78. Эффект BACKWARD − FORWARD = **0.00 процентных пункта**. Двусторонний точный тест Мак-Немара **p=1.000** (заранее заданный alpha=0.05).

**Первичная гипотеза об улучшении J при обратном поиске не подтверждена.** Результат не доказывает математическую эквивалентность методов и не разрешает выбирать другую первичную метрику после просмотра TEST.

Два алгоритма с D2 выполнены с нуля, без доступа к ответам D1, и каждый имел собственный бюджет Q16:

| Показатель при D2, Q16 | FORWARD | BACKWARD |

Различие между D1 и D2 показывает, что **донор влияет на охват и выбранное объяснение не меньше, чем направление поиска**. Здесь D2 — вторая по расстоянию TRAIN-запись, а не независимый субъект и не датасет из другой организации. Статистический тест по D2 не был первичным и не используется для постфактум объявления победителя.

## Стабильность при смене донора: два разных вопроса

**1. Независимый повторный поиск с новым донором (D2).** Среди 71 первичных J(D1)-успехов:
- FORWARD: J(D2) на том же TEST окне подтвердился в **63/71**;
- BACKWARD: J(D2) подтвердился в **60/71**.

Это НЕ означает, что совпали те же фрагменты: алгоритм на D2 выбирал собственную маску. Среди примеров, где оба независимо найденных контрфакта вообще переключили B, медианный Jaccard индексов выбранных блоков равен **≈0.6905** у обоих методов. Это умеренное совпадение, не инвариантное объяснение.

**2. Перенос того же найденного множества блоков с D1 на D2.** Для каждого непосредственно подтверждённого D1-контрфакта зафиксирована та же маска и выполнен ровно один дополнительный вызов чёрного ящика с **другим** донором. Проверка проводилась после всех онлайн-поисков; не использовалась для построения D1-объяснений. За эти обращения не выдаётся бесплатная Q16-гарантия: они записаны отдельным OFFLINE AUDIT.

| Перенос без изменения индексов блоков | FORWARD | BACKWARD |
| --- | ---: | ---: |
| D1 дал подтверждённое переключение B | 103 | 98 |
| Та же маска + D2 всё ещё переключает B | 71/103 | 66/98 |
| Среди 71 случаев J(D1): та же маска + D2 переключает B и сохраняет <=35% изменений | **51/71** | **50/71** |

Переносная проверка **не подтверждает** 1-deletion минимальность для D2; её надо проверять дополнительными запросами, которые здесь не выполнялись. Таким образом, донорная устойчивость объяснений частичная и сильно зависит от определения «того же объяснения». При простом независимом перезапуске два метода выглядят устойчивее, чем при фиксированной переносимой маске.

## Научный вывод

Преимущество BACKWARD из предшествующего исследовательского этапа BasicMotions по числу локально проверенных компактных объяснений **не воспроизведено** на отдельном корпусе RacketSports. Обе политики дали 71/152 по **строгой заранее зафиксированной метрике**. Донорная проверка выявила более серьёзное ограничение: только 50/71 строгих BACKWARD-объяснений пережили перенос выбранных **тех же блоков** на D2 с сохранением целевого класса и порога <=35%.

**Дальше нужен не подбор гиперпараметров по этому TEST, а метод отбора объяснений, учитывающий устойчивость к нескольким TRAIN-донорам уже на обучающей/калибровочной части**, при честном росте числа Q или строгом ограничении общей стоимости. Такой метод должен быть разработан и зафиксирован на TRAIN либо на новых данных, прежде чем проверяться на другом до сих пор не исследованном корпусе. Нельзя объявлять найденный результат доказательством причинности, универсальности BEACON или физической правдоподобности вставок.
